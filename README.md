# Thalia Sodi Eyewear — despliegue público

Paquete de despliegue del sitio público y del portal de clientes de Thalia Sodi Eyewear.

- Sirve la compilación pública desde `public/`.
- Mantiene el portal de clientes bajo el mismo origen.
- Reenvía únicamente las rutas `/api/client-*` al backend privado existente.
- No contiene credenciales ni los archivos privados del portal.

El repositorio fuente completo permanece privado.
