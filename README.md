# Thalia Sodi Eyewear — despliegue público

Paquete público y precompilado del sitio de Thalia Sodi Eyewear.

- GitHub Pages sirve la portada, los catálogos B2B/B2C, las fichas y el blog desde `public/`.
- La URL temporal de GitHub se usa para validar el sitio antes de asociar `thalia-innova.com`.
- El dominio final previsto continúa siendo `https://thalia-innova.com/`.
- GitHub Pages no ejecuta las rutas privadas `/api/client-*`; el acceso autenticado del portal debe conservar un backend separado antes del cambio de dominio.
- Este repositorio no contiene credenciales ni los archivos privados del portal.

El repositorio fuente completo permanece privado.
